# 仏滅の夜

霧ヶ沼キャンプ場で、7人の学生と「カカシ男」が夜明けまでの20分を争う、3Dのホラー鬼ごっこ。
学生(逃げる側)でも、カカシ男(追う側)でも遊べます。ブラウザだけで動きます(パソコン・スマホ)。

**遊ぶ:** https://tanakatakeshi811-spec.github.io/butsumetsu-no-yoru/

## できること

- **ひとりで遊ぶ**: 足りない役はコンピューターが動かす
- **クイックプレイ(P2P)**: ほかのプレイヤーと最大8人で遊ぶ。部屋を作った人(ホスト)が計算して、ほかの人と直接つながる。足りない人数はコンピューター
- **学生の勝ち方**: 車(4人)・トラック(2人)・ボート(2人)で逃げる / 管理棟の電話で警察を呼ぶ / 20分生きのびる / カカシ男の仮面をはがして、たおれた時にお札を貼る(封印)
- **カカシ男の力**: 霧渡り(瞬間移動)・影走り(0:20 から・7 秒ごと)・気配・忍び足。時間がたつと使えるようになり、15分で怒る
- **飛びかかり**: カカシ男はこうげきボタンを長押しすると、前に 5m 飛びかかる。外すと少しのあいだたおれる
- **窓**: ふつうに乗りこえると約 2.5 秒。走って飛びこむと速いけれど、ケガをして 3.5 秒たおれる
- **こわさ**: カカシ男に見つかったりケガをさせられたりすると上がる。冷静な学生ほど上がりにくい。こわいとスタミナが戻りにくく、パニックになると修理もむずかしい
- **パーク 46 種類**: 試合でもらえる CP で「ひく」。学生1人に3つまで。「すばやさこそ正義」「脳筋で何が悪い」「肉壁」のような、くせの強いパークもある
- **つかみ**: カカシ男につかまれても、連打でぬければカカシ男は 2.3 秒動けない
- **持ち物**: 地図とトランシーバーはポケットに入らない。ポケットの道具は数字を長押しすると落とせる
- **構え**: 構えたままのこうげきは 1.75 倍。カカシ男はガード、学生は回避もできる(回避は 8 方向それぞれちがう動き)
- **動き**: ドアは手をのばして開ける、窓は両手で持ち上げる、乗りこえは手をついて足をかけてまたぐ。バットは横ぶり、フライパンは上からたたく。歩き方・走り方は男女でちがう

## 操作(パソコン)

| キー | 学生 | カカシ男 |
|---|---|---|
| WASD | 歩く | 歩く |
| Shift | 走る | 影走り |
| E | 調べる・拾う・ドア・かくれる・乗る・窓(走りながらで飛びこむ) | つかむ・ドア・かくれ場所を調べる |
| 左クリック / 右クリック長押し | こうげき / 構え | こうげき(長押しで飛びかかり) / 構え(ガード) |
| スペース | 修理のタイミング・連打・回避 | とどめ・ひるんだら連打 |
| Tab | 地図(地図を持っている時) | 地図 |

スマホは横向きで、左側がスティック、右側をなぞると見回す、ボタンは右下です。カカシ男の「攻撃」は長押しで飛びかかりです。

## P2P について

クイックプレイは [Trystero](https://github.com/dmotz/trystero)(MIT ライセンス)を使った WebRTC の P2P です。
相手を見つける合図だけ Nostr の公開リレーを使い、試合のデータはプレイヤーどうしで直接やりとりします。
P2P なので、いっしょに遊ぶ人にはおたがいのネットの住所(IP アドレス)が伝わります。名前には本名を入れないでください。
